# Emberdale — a top-down medieval RPG for the browser

Plain JavaScript + HTML5 Canvas 2D. No engine, no frameworks, no build step.

## Running

The game uses ES modules, so it needs a static server (opening `index.html`
via `file://` won't work):

```sh
python3 -m http.server 8000
```

Then open:

- **Game**: http://localhost:8000/ *(Phase 1 — built after art approval)*
- **Sprite review page**: http://localhost:8000/tools/review.html

## Project layout

```
index.html          entry point (Phase 1)
src/                game modules (Phase 1)
assets/sprites/     generated PNG spritesheets + manifest.json
tools/gen_sprites.py   sprite generator — draws every sprite in code
tools/review.html      sprite gallery: 8× + 1× views, live animations, palette
```

## Art pipeline

All art is generated by `tools/gen_sprites.py` (pure Python stdlib — it writes
PNGs with zlib directly). Sprites are drawn as ASCII pixel grids over a single
32-colour master palette (Endesga 32), one character per pixel, with a
top-left light source and dark outlines throughout.

```sh
python3 tools/gen_sprites.py          # regenerate everything
python3 tools/gen_sprites.py player   # regenerate just one sheet
```

`assets/sprites/manifest.json` describes every animation (sheet, row, frame
count, fps) and is consumed by both the review page and the game.
